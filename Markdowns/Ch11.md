## Archivos

En una computadora, los datos se guardan en archivos. Los archivos pueden tener todo tipo de datos y de formatos. La extensión del archivo .jpg, .pdf, etc. denota la estructura y tipo de datos en un archivo.

Como parte del curso vamos a centrarnos en unos tipos de datos específicos:

1. **.txt:** Es un archivo de texto, contiene una serie de caracteres, es prácticamente una string en un archivo.

2. **.csv:** Acrónimo de Comma Separated Values, contiene una serie de datos separados por comas, cada lina denota una fila, cada coma una columna dentro de la fila.

3. **.xlsx:** Archivo de excel, en realidad es muy parecido a un csv. Contiene una serie de filas y columnas.

4. **.jpeg:** Archivo de imagen, contiene código binario que describe una imagen.

Python nos permite leer todo tipo de archivos, esto se logra mediante una variable de tipo File que guarda un archivo. Un ejemplo de código de como hacerlo es:

```
arch = open("ejemplo.txt") # open carga el archivo
```

La subrutina open() tiene un segundo parámetro que decide la forma en la que se abre el archivo, los posibles valores son:

- **r:** Hace que solo sea posible leer, no editar el archivo

- **w:** Hace que se pueda leer y editar el archivo

- **a:** Hace que al escribir se escriba al final del archivo, evitando modificar la información que ya existe

- **x:** Hace que se cree un nuevo archivo, puede generar errores

En código, esto se ve de la siguiente manera:

```
arch = open("ejemplo.txt", "w") # open carga el archivo
```

También se puede específicar el tipo de archivo:

- **t:** Archivo de texto 

- **b:** Archivo binario 

Un ejemplo en código es:

```
arch = open("ejemplo.txt", "rb") # open carga el archivo
```

### Lectura

Para leer existen los métodos **read()** y **readlines()**:

```
arch = open("ejemplo.txt")
print(arch.read()) # read lee una línea del archivo
print(arch.readlines()) # readlines lee todo el archivo
```

También tenemos la opción de leer una cantidad específica de líneas con readlines():

```
arch = open("ejemplo.txt")
print(arch.readlines(3)) # readlines lee 3 líneas
```

Al terminar de utilizar un archivo utilizamos **.close()** para cerrarlo:

```
arch = open("ejemplo.txt")
print(arch.readlines())
arch.close()
```

### Escritura

El método **write()** nos permite escribir dentro de un archivo:

```
arch = open("ejemplo.txt", "w")
arch.write("Hola Mundo")
arch.close()
```

## Pandas

Pandas es una biblioteca de manejo de datos, su objetivo es poder leer archivos con grandes cantidades de datos y realizar diferentes tipos de operaciones sobre ellos. Es muy usada para ciencia de datos y para aprendizaje de máquina.

Pandas funciona encima de NumPy, usando los arrays de NumPy para guardar y manejar sus datos. Cada columna de un dataframe de Pandas es un array 1d de NumPy. Este uso permite que, a diferencia de los arrays normales, podamos mantener diferentes tipos de datos dentro de una sola estructura mientras al mismo tiempo seguimos aprovechando las ventajas dadas por los arrays. Pandas también permite darle mayor estructura a los datos, agregando nombres de columnas para mayor claridad.

### Dataframe

Al leer un archivo con muchos datos (generalmente un .csv) pandas crea una estructura que le permite guardar todo en una sola variables. Estos datos son guardados en una tabla llamada **dataframe** que a su vez está compuesta por múltiples columnas llamadas **series** las cuales pueden tener diferentes tipos de datos.

En algunos casos los archivos con los que creamos el dataframe pueden tener espacios vacios en sus datos, en ese caso se utiliza la variable **NaN** vista anteriormente.

#### Creacion

Hay diferentes formas de crear un dataframe, puede crearse a mano con las estructuras vistas anteriormente, por ejemplo:

1. Diccionario:

```
import pandas as pd
base = {
    "nombres" : ["Carlos", "Juana", "Marco"],
    "edad" : [22, 25] 
}
datos = pd.DataFrame(base)
print(datos)
# Imprime
#   nombres  edad
# 0  Carlos    22
# 1   Juana    25
# 2   Marco   NaN
```

2. Listas:

```
import pandas as pd
base = [["Carlos", 22], ["Juana", 25], ["Marco"]]
datos = pd.DataFrame(base, columns = ["nombres", "edad"])
print(datos)
# Imprime
#   nombres  edad
# 0  Carlos    22
# 1   Juana    25
# 2   Marco   NaN
```

3. Arrays:

```
import numpy as np
import pandas as pd
base = np.array([["Carlos", 22], ["Juana", 25], ["Marco", np.nan]])
datos = pd.DataFrame(base, columns=["nombres", "edad"])
print(datos)
# Imprime
#   nombres  edad
# 0  Carlos    22
# 1   Juana    25
# 2   Marco   NaN
```

Al usar arrays, hay que tener cuidado con los tipos de datos, en el ejemplo visto la columna edad no contiene números, contiene strings, por lo que hay que convertirla antes de usarlo. La conversión se hace con la subrutina **.astype()**, esto se hace de la siguiente manera:

```
import numpy as np
import pandas as pd
base = np.array([["Carlos", 22], ["Juana", 25], ["Marco", np.nan]])
datos = pd.DataFrame(base, columns=["nombres", "edad"])
datos["edad"] = datos["edad"].astype(float) # Convierte toda la columna a floats
print(datos) 
# Imprime
#   nombres  edad
# 0  Carlos  22.0
# 1   Juana  25.0
# 2   Marco   NaN
```

#### Propiedades

Los dataframes tienen ciertos atributos, entre ellos están:

**ndim:** Retorna la cantidad de dimensiones del dataframe (en general van a ser 2)

**shape:** Retorna la cantidad de filas y columnas del dataframe

**size:** Retorna la cantidad de datos en el dataframe

**index:** Retorna la lista de los índices del dataframe (por defecto el número de la fila)

**columns:** Retorna los nombres de las columnas

**info:** Retorna una serie de información del dataframe incluyendo cantidad de datos, tipos de dato de cada columna, cantidad de columnas, nombre de columnas, etc.

### Lectura de archivos

En general, crear dataframes desde 0 no es tan manejable, por lo tanto es preferible crearlos a partir de los datos de un archivo. Para crearlos, simplemente se utilizan la subrutina que lee ese tipo de archivo.

1. .csv:

```
import pandas as pd
base = pd.read_csv("datos.csv")
print(datos) 
```

2. Excel:

```
import pandas as pd
base = pd.read_excel("datos.csv")
print(datos) 
```

Al leer estos datos, es posible elegir cuál de las columnas es tomada como el índice principal. Por ejemplo:

Tenemos el siguiente .csv llamado datos.csv:

```
nombres,edad
Carlos,22
Juana,25
Marco,nan
```

**Nota:** La primera fila de los .csv contiene los nombres de la columna.

Al cargar datos usando read_csv(), se puede usar un parámetro opcional llamado **index_col** que permite elegir una columna índice. Un ejemplo es:

```
import pandas as pd
datos = pd.read_csv("datos.csv", index_col="nombres")
print(datos)
```

### Selección de datos

Al ser estructuras complejas, existen muchas formas diferentes de seleccionar los datos de un dataframe. Algunas de las formas de accesar datos son:

**[ ]:** Selecciona una columna específica con su nombre, similar al funcionamiento de los mapas. Ejemplo:

```
import pandas as pd
df = pd.read_csv("datos.csv")
print(df["edad"]) 
# Imprime
# 0    22.0
# 1    25.0
# 2     NaN
```

También se pueden tomar múltiples columnas:

```
import pandas as pd
df = pd.read_csv("datos.csv")
print(df[["edad", "nombres"]])
# Imprime
#    edad nombres
# 0  22.0  Carlos
# 1  25.0   Juana
# 2   NaN   Marco
```

**loc[ ]:** Toma una fila específica buscando por su columna índice.

```
import pandas as pd
df = pd.read_csv("datos.csv", index_col="nombres")
print(df.loc["Juana"])
# Imprime
# edad    25.0
```

Permite múltiples filas:

```
import pandas as pd
df = pd.read_csv("datos.csv", index_col="nombres")
print(df.loc[["Juana", "Marco"]])
# Imprime
# nombres  edad     
# Juana    25.0
# Marco     NaN
```

Podemos tomar columnas específicas de esas filas:

```
import pandas as pd
df = pd.read_csv("datos.csv", index_col="nombres")
print(df.loc[["Juana", "Marco"], ["edad"]])
# Imprime
# nombres  edad     
# Juana    25.0
# Marco     NaN
```

**iloc[ ]:** Toma una fila según su posición. También permite múltiples filas y columnas específicas.

```
import pandas as pd
df = pd.read_csv("datos.csv")
print(df.iloc[0])
# Imprime
# nombres    Carlos
# edad         22.0
```

**at[ ]:** Muy similar a loc[ ], solo permite una fila y columna específicos.

```
import pandas as pd
df = pd.read_csv("datos.csv", index_col="nombres")
print(df.at["Juana", "edad"])
# Imprime
# 25
```

**iat[ ]:** Similar a iloc[ ], pero recibe una posición y un número específicas.

```
import pandas as pd
df = pd.read_csv("datos.csv")
print(df.iat[0, 1])
# Imprime
# 22
```

**Booleanos:** También podemos hacer revisiones buscando según una condición. Por ejemplo:

```
import pandas as pd
df = pd.read_csv("datos.csv")
print(df[(df["edad"] > 20) and (df["nombres"] == "Juana")])
# Imprime
#   nombres  edad
# 1   Juana  25.0
```

Si quiero una columna específica, se utiliza loc[ ]:

```
import pandas as pd
df = pd.read_csv("datos.csv")
print(df.loc[df["edad"] >= 25, "edad"])
# Imprime
# 1    25.0
```

**Nota:** Los operadores para los condicionales son: ~ - not, & - and, | -  or, ^ - xor

### Modificación

Existen diferentes cambios que se pueden realizar sobre un dataframe ya creado.

#### Asignar

Para asignar datos simplemente se utiliza alguno de los métodos de selección de datos donde se toma una columna específica y el operador **=**.

```
import pandas as pd
df = pd.read_csv("datos.csv")
df.iloc[0, 0] = 50
print(df)
# Imprime
#   nombres  edad
# 0      50  22.0
# 1   Juana  25.0
# 2   Marco   NaN
```

Funciona con booleanos:

```
import pandas as pd
df = pd.read_csv("datos.csv")
df.loc[df["edad"] >= 25, "edad"] = 100
print(df)
# Imprime
#  nombres   edad
# 0  Carlos   22.0
# 1   Juana  100.0
# 2   Marco    NaN
```

#### Insertar

**Filas:** Para agregar filas se utiliza el metodo **.concat()**. Este método recibe 2 dataframes y los junta, por lo tanto es necesario crear un dataframe con la nueva fila.

```
import pandas as pd
df = pd.read_csv("datos.csv")
nuevoBase = {"nombres" : ["Luis"], "edad": [19]}
nuevo = pd.DataFrame(nuevoBase)
df = pd.concat([df, nuevo], ignore_index=True)
print(df)
# Imprime
#   nombres  edad
# 0  Carlos  22.0
# 1   Juana  25.0
# 2   Marco   NaN
# 3    Luis  19.0
```

**Columnas:** Se crean de la misma forma que en los diccionarios, simplemente se usa [ ] con un nombre de columna nuevo y se asigna un valor. Por ejemplo:

```
import pandas as pd
df = pd.read_csv("datos.csv")
df["salario"] = 500
print(df)
# Imprime
#   nombres  edad  salario
# 0  Carlos  22.0      500
# 1   Juana  25.0      500
# 2   Marco   NaN      500
```

#### Eliminar

**Filas:** Se utiliza la subrutina **drop( )**, esta funciona a partir del índice

```
import pandas as pd
df = pd.read_csv("datos.csv", index_col="nombres")
df = df.drop(["Marco"])
print(df)
# Imprime
# nombres  edad   
# Carlos   22.0
# Juana    25.0
```

**Columnas:** Se utiliza drop( ), pero se utiliza el parámetro **axis = 1**.

```
import pandas as pd
df = pd.read_csv("datos.csv")
df = df.drop("nombres", axis=1)
print(df)
# Imprime
#    edad
# 0  22.0
# 1  25.0
# 2   NaN
```

#### Ordenamiento

**sort_index( ):** Ordena según la columna índice:

```
import pandas as pd
df = pd.read_csv("datos.csv", index_col="nombres")
df = df.sort_index()
print(df)
# Imprime
# nombres  edad   
# Carlos   22.0
# Juana    25.0
# Marco     NaN
```

**sort_values( ):** Ordena según una o varias columnas.

1. 1 Columna:

```
import pandas as pd
df = pd.read_csv("datos.csv")
df = df.sort_values(by="edad")
print(df)
# Imprime
# nombres  edad   
# Carlos   22.0
# Juana    25.0
# Marco     NaN
```

2. Múltiples Columnas:

```
import pandas as pd
df = pd.read_csv("datos.csv")
df = df.sort_values(by=["edad", "nombres"])
print(df)
# Imprime
# nombres  edad   
# Carlos   22.0
# Juana    25.0
# Marco     NaN
```

**rank( ):** Retorna una lista diciendo el orden que tendrían los datos si se ordenaran según una fila. Por ejemplo:

```
import pandas as pd
df = pd.read_csv("datos.csv")
print(df[edad].rank())
# Imprime
# 0    1.0
# 1    2.5
# 2    2.5
# 3    NaN
```

### Operaciones

#### Aritmética

Se pueden realizar las operaciones aritméticas de Python sobre columnas específicas del dataframe o incluso sobre toda la estructura.

```
import pandas as pd
df = pd.read_csv("datos.csv")
df["edad"] *= 2
print(df)
# Imprime
#   nombres  edad
# 0  Carlos  44.0
# 1   Juana  50.0
# 2   Marco   NaN
```

```
import pandas as pd
df = pd.read_csv("datos.csv")
df *= 2
print(df)
# Imprime
#         nombres  edad
# 0  CarlosCarlos  44.0
# 1    JuanaJuana  50.0
# 2    MarcoMarco   NaN
```
También se pueden realizar entre dataframes compatibles:

```
import pandas as pd
df = pd.read_csv("datos.csv")
df *= 2
df2 = pd.read_csv("datos.csv")
print(df + df2)
# Imprime
#               nombres  edad
# 0  CarlosCarlosCarlos  66.0
# 1     JuanaJuanaJuana  75.0
# 2     MarcoMarcoMarco   NaN
```

#### Crear columnas

Es posible crear columnas nuevas a partir de operaciones realizadas sobre la fila. Por ejemplo:

```
import pandas as pd
df = pd.read_csv("datos.csv")
df["Mayor"] = df["edad"] >= 18
# Imprime
#   nombres  edad  Mayor
# 0  Carlos  22.0   True
# 1   Juana  25.0   True
# 2   Marco   NaN  False
```

#### Uso de NumPy

Muchos de los métodos utilizados para hacer cálculos sobre arrays de NumPy funcionan sobre columnas de Pandas, entre estos estan: sum, min, mean, median, max, min, etc. Se usan de la siguiente forma:

```
import pandas as pd
df = pd.read_csv("datos.csv")
print(df["edad"].max())
# Imprime
# 25
```

#### Iteración

El crear un for sobre un dataframe puede ser un poco más dificil de lo esperado, no se puede hacer un simple for dato in datos, se deben utilizar los métodos de Pandas. Estos métodos son:

**items( ):** En cada iteración retorna el nombre de una columna y una tupla que contiene los valores de esa columna. Su uso se ve así:

```
import pandas as pd
df = pd.read_csv("datos.csv")
for indice, datos in df.items():
    print(f"Indice: {indice}, \ndatos:\n{datos}")
# Imprime
# Indice: nombres, 
# datos:
# 0    Carlos
# 1     Juana
# 2     Marco
# Name: nombres, dtype: object
# Indice: edad, 
# datos:
# 0    22.0
# 1    25.0
# 2     NaN
# Name: edad, dtype: float64
```

Si queremos hacer iteración sobre una columna específica, hacemos lo siguiente:

```
import pandas as pd
df = pd.read_csv("datos.csv")
for datos in df["nombres"]:
    print(f"datos: {datos}")
# Imprime
# datos: Carlos
# datos: Juana
# datos: Marco
```
